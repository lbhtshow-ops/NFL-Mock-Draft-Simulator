# Retained Research Source Packages

This directory is reserved for reviewed, repository-retained authoring packages. Create each package in a directory named `rsp-####-short-subject-and-artifact-label` and begin from `../templates/`. Each directory represents exactly one stable primary source artifact. Use separate package directories for materially different pages, reports, releases, episodes, videos, files, interviews, or dataset versions concerning the same subject.

No real package is present yet. Material placed here remains subject to source access, copyright, privacy, provenance, human-review, and authorization rules. Never commit credentials, API keys, access tokens, private medical records, restricted personal information, full copyrighted articles, or content whose terms prohibit retention. A retained file is not automatically approved evidence or authorized for Population use.
