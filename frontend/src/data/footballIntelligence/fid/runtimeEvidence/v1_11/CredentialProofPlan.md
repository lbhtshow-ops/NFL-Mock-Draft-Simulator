# Credential proof plan

Design only. A later proof establishes only that the reviewed provider can supply one credential to the Node-only process, with no value in prompt transcript, command history, logs, evidence, source control, environment dumps, or errors. It tests sanitized absence/failure/operator-cancellation behavior using an approved mechanism, releases the credential after the single attempt, records only provider/reference/status metadata, and stops. The operator must never paste the credential into Codex or ChatGPT. Credential proof is not connection or SQL authorization.
